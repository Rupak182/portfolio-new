## Core Architectural Concepts I am Learning

To design scalable software, we must address several fundamental system requirements:

1.  **Scalability**: The capacity of a system to handle growing volumes of work by adding computational resources.
    *   **Vertical Scaling**: Upgrading the hardware (CPU, RAM) of a single server.
    *   **Horizontal Scaling**: Adding more servers to distribute the traffic.
2.  **Availability**: The proportion of time the system remains operational and accessible.
3.  **Reliability**: The likelihood that a system performs its intended function under specified conditions without failures.
4.  **Fault Tolerance**: The system's ability to keep running correctly even if one or more components fail.
